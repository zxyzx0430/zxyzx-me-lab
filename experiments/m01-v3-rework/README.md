# M01 / Home Hero — V3 构图改稿 V2（DRAFT）

这是用户明确喜欢的 **V3 原始首屏构图** 的定向修改，而非新的首页设计方向。当前**仅供审看**，未正式批准，也没有集成进整个网站。

## 保留的 V3 视觉基线

- 奶油暖白的大面积底色与轻颗粒质感
- 右侧倾斜裁切的大幅人物照片，保留原 V3 的空间比例
- 巨型黑字与白色前景中文字在人物面前/后面穿插
- 背景稀疏椭圆弧线、极淡轮廓巨字和精细角落标签
- 滚动时人物和字层不同速度移动，用户始终可直接滚动
- 桌面和手机使用不同构图比例，手机侧重人物脸部

## 根据已讨论内容做的替换

- 顶部个人主标识 **忠心于中心**（ZXYZX.ME 是域名，不作为品牌主名）
- 核心主标题 **向内寻找中心，向外探寻世界。**
- 品牌精神 **忠于内心的原则，也寻找问题的本质。**
- 本人自拍经灰调电影式处理并作为首屏照片，不再使用原 V3 的模特占位图
- 原 V3 额外的项目、财务、硬件章节并未修改或复制；底部只保留「思想，进入现实」的 M01 → 下一幕边界演示

## 文件结构

- `index.html` — 单文件、离线可打开的独立审看页（含高质量人像）
- `index-modular.html` — 模块化入口，使用独立 CSS/JS/素材
- `module.js` — Web Component `zxyzx-home-hero-v3`，仅控制自己的交互
- `module.css` — Shadow DOM 隔离样式与响应式规则
- `assets/portrait-user-v3.webp` — 经授权的本人肖像艺术化素材
- `README.md` — 本文档
- `test.mjs` — 独立静态合同测试
