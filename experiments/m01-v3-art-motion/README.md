# M01 · V3 Art Motion (独立实验稿)

**Status: Draft / Pending User Review**

本版本继承获认可的原始 V3 构图，而不是沿用深色 M01 V1：暖白底色、右侧倾斜的电影式肖像、两行巨型中文黑白对比、极细的环形线条、底部编辑式信息。

核心品牌：**忠心于中心**。核心宣言：**向内寻找中心，向外探寻世界**。

## 艺术人物

- 使用根据用户本人面部照片生成的 **AI 艺术肖像素材**，不是原始自拍；黑白冷暖胶片调色、侧光、眼镜与蓬松发型。
- 人像和网站文字分开实现，文字是可渲染和可更改的真正网页文字，不是海报平面截图。
- 肖像资源内嵌在独立 HTML 中以便 GitHub Pages 使用，未来如需高清摄影可以只替换这一素材。
- 人物肖像及设计素材仅用于当前个人网站实验，不代表用户真实拍摄现场。

## 动效

- 首屏人物提前可见，中文通过交错 **剪纸遮罩（mask reveal）** 出场。
- **整屏翻页（本次更新）**：首屏由 170svh 缩为 100svh；鼠标滚轮一次明确动作直接切换到暗色下一幕，向上可返回；手机轻扫和键盘方向键 / PageDown 通过轻量翻页控制直接换幕，不再使用原生强制吸附。无需长距离滚动。
- 翻页途中，两组文字分别向左上、右下运动，人物进行微弱景深位移；保留 V3 静态构图和艺术肖像。
- 细微鼠标视差，触摸屏自动避免无意义的追踪。
- 降低动态效果（prefers-reduced-motion）时不播放入场或滚动视差，保留静态构图。
- 事件清理（scroll / resize / pointer）均包含在独立 Web Component 内。

## 版本边界

- **仅有 M01 首屏和过渡示意**，不是 M02 项目世界实现。
- 旧 V3、M01 V1、V3 Rework V2、正式 zxyzx.me 与 approved Knowledge Network V5 未改动。
- 完整独立入口：`experiments/m01-v3-art-motion/index.html`。
- 用户验收前不会标记为 approved / frozen。

Chromium 验证宽度：1440×900、768×1024、390×844、320×680；没有脚本错误、图片正常、无水平溢出；减少动态模式关闭动画。

## 巨型中文排版精修（2026-10-28）

- 保留 V3 暖白底、倾斜艺术肖像与黑白字体对撞；不修改人像素材或翻页动画。
- 将主标题拆为独立字号层级：**「向内」「向外」** 保留主视觉的大字，**「寻找中心，」「探寻世界。」** 改为较小的编辑式补充文字。
- 取消按固定百分比切割单个汉字颜色的渐变。桌面端白色「探寻世界。」落在肖像下方深色衣服上，不再穿过眼睛；手机端黑白切换在**汉字之间**完成，而不是切开笔画。
- 把解释性文案放在与巨型标题分离的位置，保持人物眼睛及面部有完整阅读空间。
- 独立测试 1590、1440、768、390、320px 与一滑一页行为。本版仍为 Draft。
