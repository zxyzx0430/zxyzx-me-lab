## 1. 目标与设计哲学（为什么这样做）

- 个人站：`zxyzx.me`，主品牌：**「忠心于中心」**；「ZXYZX」只作拼音/域名的次要签名，**不能代替主 Logo**。
- 第一眼先认出「这个人是谁」，**然后才理解他在做什么项目**。M01 不是企业宣传页、AI 科技公司介绍，也不是普通的卡片作品集。
- 双重含义：忠于自己的内在原则 + 寻找问题最本质的中心。内在的思辨与外在世界的探索互为因果。
- 核心宣言完整精确：**「向内寻找中心，向外探寻世界」**；可在版式中分别断行为「向内｜寻找中心，」「向外｜探寻世界。」；不可擅自改词。
- 全站定位：**电影式个人开场 + 独立项目世界**。首页是个人展览；M02 是作品入口；M03+ 是各项目的深潜世界。项目拥有不同表达方式。

## 2. 已经被用户认可的视觉（不要再从头推翻）

用户多次明确表示喜欢 **原始 V3 首屏构图**，不喜欢早期黑色 M01 V1。此认可的基准元素是：

1. **暖白 / 淡米色画布**，偏摄影纸张而非科技黑屏；有克制的灰线、椭圆弧、淡化的几何线稿。
2. 右侧**向一侧轻微倾斜的大幅黑白电影艺术肖像**，真实人物面部为主体；眼镜、蓬松头发、面部与手的姿态形成沉静凝视。人物素材是以用户照片为参考生成的 AI 艺术照，**不是用户真实拍摄的那张照片**。
3. 左侧**巨大的黑色简洁粗体中文**，与人物产生跨界与前后景关系。关键词「向内」「向外」是大字，后半句「寻找中心，」「探寻世界。」是相对较小的次层级；局部白字置于照片深色衣服，**不要让粗暴的黑白渐变切开汉字笔画**。
4. 重点必须留出**人物眼睛、面部和摄影光线**。字与人共同形成一张完整电影海报；不是单独一张头像加单独一组标题。
5. 页眉左侧完整字标「忠心于中心」；右侧小型 WORK/ABOUT 与细节编号；底部编辑式英文辅助信息和短中文思想说明。**信息清楚但克制，英文不是主要品牌名**。
6. **静止的第一屏就必须好看**，动画只是帮助观察和转场，不是填满视觉空间的装饰物。

原型截图参考： [固定截图验收站](https://zxyzx0430.github.io/zxyzx-me-lab/review/m01/) — 目前只采用 **1920×1080**。用户明确取消了 1440×900 作为固定截图规格。

## 3. 动画与交互思想（不能退回长距离拖动）

- 初次进入：人物已存在；巨型中文采用交错剪纸遮罩出场。快速形成张力，随后归于平静。
- 视觉的滚动意象：「向内」的文字渐渐向画面外退，人物微幅推进或漂移，再进入与「向外」有关的作品世界；避免无意义的永恒漂浮、重复弹出、科技粒子。
- **翻页体验是关键已验收点**：用户投诉过原 170svh 的“滚很长才到下一屏”，视觉上像卡顿；当前已经修成约 100svh，**一次明确的滚轮动作切换下一幕、向上返回**。手机轻扫、键盘 PageUp/PageDown/方向键同样可用。
- 不采用会导致部分浏览器首屏自动落到第二幕的强制 scroll-snap；当前实现是轻量交互控制。后续改动要保留“短距离动作即换幕”和首屏稳定初始位置。
- 尊重 `prefers-reduced-motion`、触控屏可用性、键盘交互；不能锁住全站滚动或阻断正常导航。

## 5. 明确批准的范围 / 未冻结范围

**已批准：** 当前 V3 静态整体气质、暖白背景与右侧倾斜肖像、巨型中文字层级、品牌展示方式、摄影与文字结合，以及一滑一页的总体交互体验。

**未批准或尚未实现：**
- G01 最终特制「忠」符号、全部字体文件与完整品牌 VI：只锁定名称与“字标＋符号”的方向；目前页眉是可用临时字标。
- 正式站 `zxyzx.me` 的部署与全站 React / 其他框架集成。
- 完整 M02 真实作品展示与 M03/M04/M05 项目深潜页面：V3 预览中的第二幕 **「思想，进入现实」属于转场示意，不是 M02 定稿**。
- AI 人像的永久商用高清版本、独立授权素材管理、后续移动端细节迭代与跨浏览器验收。

## 6. M01 → M02 交接接口

- M01 输出「向内寻找中心，向外探寻世界」；M02 回答**「我的思想进入了哪些真实项目？」**
- M01 的暖白色舞台 → 下一幕可出现明显的暗色/图像对比，以呈现向外打开世界的视觉变化；**不要求 M02 全暗**，只锁定转场叙事。
- M01 只负责人物开场；作品卡、项目视频、各项目介绍、内部链接属于 M02，不得回头堆在 M01 上。
- 当前实验中的 `#world` 是第二幕占位。以后由整站组合层负责联通 M01 与 M02，**不是要求 M02 直接修改 M01 的源码或 Shadow DOM**。

## 7. 修改保护规矩

1. 不得在原基准中随意动人物、字体比例、色调、视差或已认可的滚动逻辑。
2. 新想法先建新分支与版本（例：`feat/m01-v4-...`），保留老版不删。
3. 任何变更涉及 M01 的视觉和交互，都需同时提交前后对比；截图站必须展示**1920×1080** 当前和历史截图（中文不准有方框）。
4. 用户明确通过才更新下一个视觉批准标签，不以“CI 通过”代表审美批准。
5. 向其他线程交接时要发：本页、冻结标签、单模块预览地址、截图站、真实代码路径、已知限制。
